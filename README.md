*About the project:*
Protocol 372 is a multi-page informational website project that I made as part of the Goldsmith's, UoL 1st year web dev module.

Key features include:
- **Backend:** Made using node.js and express framework
-  **Templating:** Custom built template engine made using JS and regex parsing
-  **Content management:** An api.json file supplying structured content for each page
-  **Validation:** JSON scheme validation ensures all required fields are present and validated
-  **Routing:** Express handles dynamic routing to different pages (/home, /e-stonia, /global, /vision)
-  **Deployment:** Hosted live on render

Running locally: 
**Prerequisites:**
Install node.js from: https://nodejs.org/en
Then:
1. Download the zip from GitHub.
2. Extract the ZIP folder.
3. Open the terminal in the project root directory.
4. Run 'npm install' to install dependencies.
5. Run 'npm start' or 'node server.js' to start the server.
6. Open http://localhost:3000 (or the port shown in the terminal)
